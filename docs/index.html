For Authorized Cybersecurity Testing

✨ Key Features

🌍 Network Intelligence

Public IP Detection, Country Detection, Region & State Lookup, City Detection, Postal Code, Latitude & Longitude, Timezone Detection

🛰️ Geolocation

MaxMind GeoLite2 Database, Online IP Enrichment, ISP Detection, ASN Lookup, Organization Detection

📱 Browser Fingerprinting

Browser Name & Version, Device Type, Operating System, User Agent, Language, Screen Resolution, Platform, Timezone

📍 GPS Collection

Collect GPS Latitude, Longitude, and Accuracy when permission is granted. Falls back to IP-based geolocation otherwise.

📝 Information Collected

Category Information
Network IP Address, ISP, ASN, Organization
Geolocation Country, Region, City, Postal Code, Latitude, Longitude, Timezone
Browser Browser Name, Version, User-Agent, Platform, Screen Resolution, Language, Device Type
GPS Latitude, Longitude, Accuracy (Permission Required)

🚀 Quick Start

git clone https://github.com/DhamrpreetSingh/IP-Tracker.git
cd IP-Tracker
python -m venv .venv
source .venv/bin/activate  # On Windows: .\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python tracker.py
